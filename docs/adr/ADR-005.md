# ADR-005 — Multi-Tenant: Shared Database + tenant_id + Row-Level Security

**Estado:** Approved (ratificado en Gate 0 / G0-001)
**Fuente:** Libro 03; ratificación en Gate 0

## Decisión
Aislamiento Multi-Tenant mediante base de datos compartida, columna `tenant_id` en toda tabla operativa, y políticas de Row-Level Security de PostgreSQL. El aislamiento a nivel de aplicación es una primera capa obligatoria, NUNCA un sustituto de RLS -- ambas capas son requeridas, no alternativas.

## Ratificación en Gate 0 (G0-001)
Se confirma sin cambios. Se añaden como criterios de aceptación explícitos:
- Toda conexión debe establecer `app.current_tenant` antes de ejecutar cualquier consulta de negocio.
- Ningún rol de aplicación ordinario tendrá el privilegio `BYPASSRLS`.
- Las políticas RLS se crean en la misma migración que crea la tabla, nunca en una migración posterior.

Implementación de referencia (Fase 0): `apps/api/prisma/migrations/0001_init_foundation/migration.sql` y `apps/api/src/common/database/prisma.service.ts`.
