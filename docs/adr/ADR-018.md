# ADR-018 — Selección de ORM: Prisma

**Estado:** Approved (ratificado)
**Fuente:** Fase 0 (propuesta); ratificado al cierre de la Fase 0

## Decisión
Se adopta oficialmente Prisma ORM como tecnología de acceso a datos para CoffeeOS Enterprise. Prisma pasa a formar parte de la arquitectura oficial junto con NestJS, PostgreSQL, Docker y TypeScript.

## Contexto (histórico)
El Libro 04 (cap. 18) dejó pendiente la selección de ORM. Se propuso Prisma en Fase 0 por su soporte de `SET LOCAL` para el contexto de tenant (RLS, ADR-005), generación de tipos TypeScript y tooling de migraciones maduro. Alternativas consideradas: TypeORM, Drizzle.
