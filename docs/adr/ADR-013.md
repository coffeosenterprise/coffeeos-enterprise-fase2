# ADR-013 — Ampliación del Alcance del MVP

**Estado:** Approved
**Fecha:** 2026-07-30
**Fuente:** Libro 05 (Parte 1, secciones 5-6); registro de cierre documental

## Contexto
El Libro 01/02 definían un MVP más acotado, reservando KDS, Producción y Lealtad para "Fase 2". El Libro 04 diseñó estos módulos con el mismo nivel de detalle que el resto. El Libro 05 definió un MVP ampliado con justificación explícita de qué queda dentro y qué queda fuera.

## Decisión
El MVP oficial (Release v1.0) incluye, además de lo ya aprobado originalmente: Purchasing básico, Production básico, KDS básico, CRM básico, Notifications.

Permanecen fuera del MVP: Loyalty avanzado, Gift Cards avanzadas, IA/AI Services, Forecasting, Segmentación avanzada, Delivery, Reservaciones.

## Consecuencias
Adenda aplicada al Libro 01/02 (ver Registro de Cierre Documental). No se modifica el cronograma del Libro 05.
