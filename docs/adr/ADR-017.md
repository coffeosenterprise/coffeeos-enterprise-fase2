# ADR-017 — Alcance de Operación Offline para v1.0

**Estado:** Approved
**Fuente:** Gate 0 / G0-009

## Decisión
El MVP incluye offline básica en Sales/POS: almacenamiento local de la venta, cola de reintento, idempotencia por ID generado en cliente. No incluye resolución avanzada de conflictos ni sincronización multi-terminal compleja. Cash, Inventory y Purchasing permanecen online-only en v1.0. Las operaciones sensibles (cancelaciones, reembolsos, apertura/cierre de caja) requieren conectividad.
