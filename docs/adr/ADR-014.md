# ADR-014 — Adopción de Redis como Infraestructura Oficial

**Estado:** Approved
**Fuente:** Libro 05; registro de cierre documental

## Decisión
Redis se adopta como componente oficial de infraestructura para caché, colas complementarias y mecanismos de soporte (p. ej. rate limiting). No reemplaza el Transactional Outbox (ADR-011) como fuente de verdad de eventos de dominio.
