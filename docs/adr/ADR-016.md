# ADR-016 — Ownership de Promotion y Coupon

**Estado:** Approved
**Fuente:** Gate 0 / G0-004

## Contexto
Sales/POS y CRM/Loyalty modelaban ambos `Promotion` y `Coupon` como Aggregate Roots propios, con eventos duplicados (`PromotionApplied`, `CouponRedeemed`).

## Decisión
CRM/Loyalty es el único propietario de `Promotion`, `PromotionRule`, `PromotionReward`, `Coupon` y `CouponRedemption`. Sales/POS consume un contrato público de CRM/Loyalty y conserva un snapshot inmutable del descuento aplicado en la venta.

## Consecuencias
El Libro 04 (07.02, 07.03) queda desactualizado en este punto específico; este ADR prevalece hasta que se corrija formalmente el capítulo.
