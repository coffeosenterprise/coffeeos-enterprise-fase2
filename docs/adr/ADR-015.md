# ADR-015 — Adopción de Object Storage como Infraestructura Oficial

**Estado:** Approved
**Fuente:** Libro 05; registro de cierre documental

## Decisión
Se adopta un servicio de Object Storage compatible S3 para exportaciones (Reporting), evidencias (Audit) y plantillas (Notifications). El proveedor concreto (autoalojado vs. gestionado) queda como decisión técnica posterior.
