# ADR-001 — Monolito Modular (no microservicios en el MVP)

**Estado:** Approved
**Fuente:** Libro 03

## Decisión
CoffeeOS Enterprise se construye como un Monolito Modular con límites DDD estrictos, no como microservicios desde el inicio. Los módulos deben diseñarse con independencia suficiente para permitir extracción futura (orden de candidatos confirmado al cerrar el Libro 03: Reporting/Analytics, Sales/POS, Inventory, Integrations API, Kitchen/Production).
